# Home SOC Lab

A personal Security Operations Center lab using Splunk, Sysmon, and
MITRE ATT&CK-mapped attack simulations. Built to demonstrate end-to-end
SOC analyst skills: SIEM operations, detection engineering, attack
simulation, and incident documentation.
